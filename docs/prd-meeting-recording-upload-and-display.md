# PRD: Meeting Recording Upload and Display

**Дата**: 2026-07-31
**Статус**: Draft

## Цель

Пользователь должен иметь возможность загрузить аудио/видеозапись прошедшей встречи для хранения и последующей обработки, а также видеть загруженные записи и их статус на странице встречи.

## Пользовательские сценарии

- Пользователь открывает страницу конкретной встречи -> видит блок загрузки записи и список уже загруженных записей (если есть).
- Пользователь выбирает аудио/видеофайл и загружает его на странице встречи -> файл сохраняется, привязывается к встрече, в списке появляется запись со статусом «Загружено».
- Пользователь загружает второй файл к той же встрече -> оба файла отображаются в списке независимо друг от друга.
- Пользователь пытается загрузить файл неподдерживаемого формата или превышающий лимит размера -> загрузка отклоняется, пользователь видит понятную ошибку.
- Пользователь обновляет страницу встречи после того, как обработка файла запущена другой системой -> видит актуальный статус записи (В обработке / Готово / Ошибка) без ручных действий.
- Пользователь открывает страницу встречи, принадлежащей другому пользователю -> не видит чужие записи (доступ ограничен владельцем встречи, как и остальные данные встречи).

## В скоупе

- Страница отдельной встречи в `apps/web` (`/meetings/[id]`), которой сейчас нет — создаётся в рамках этой фичи.
- Блок загрузки файла записи на странице встречи (выбор файла, запуск загрузки, индикация прогресса/результата загрузки).
- Список загруженных записей на странице встречи: имя файла, дата загрузки, статус.
- Возможность прикрепить несколько файлов записи к одной встрече.
- API-эндпоинт(ы) для загрузки файла записи, привязанного к конкретной встрече и её владельцу.
- Хранение метаданных файла (имя, размер, формат, статус обработки, встреча-владелец) и самого файла.
- Валидация файла при загрузке: допустимые аудио/видео форматы и максимальный размер файла.
- Отображение статуса записи: «Загружено» / «В обработке» / «Готово» / «Ошибка».
- Постановка загруженного файла в очередь/пайплайн обработки (сам процесс обработки — вне скоупа, только факт постановки и отображение результирующего статуса).
- Доступ к записям встречи ограничен владельцем встречи (согласуется с текущей моделью доступа `meetings`).

## Не в скоупе

- Сама логика обработки записи (транскрибация, саммари, извлечение задач и т.п.) — реализуется отдельной фичей, здесь только точка интеграции (постановка в очередь + отображение статуса).
- Запись встречи в реальном времени (захват аудио/видео прямо во время звонка).
- Redактирование, обрезка или конвертация файла на клиенте или сервере.
- Совместный доступ к записям для участников встречи, не являющихся её владельцем.
- Возобновляемая/чанковая загрузка больших файлов (upload считается одной операцией).
- Скачивание/экспорт файла записи пользователем.
- Удаление или замена уже загруженной записи.
- Уведомления (email/push) об изменении статуса обработки.

## Технические ограничения

- Максимальный размер одного файла и поддерживаемые форматы (аудио/видео) должны быть зафиксированы явно и проверяться как на клиенте, так и на сервере.
- Загрузка не поддерживает докачку/чанкинг — файл передаётся одним запросом, что ограничивает практический максимум размера.
- Эндпоинты работы с записями встречи защищены тем же `AuthGuard`, что и остальные `meetings`-роуты, и должны проверять принадлежность встречи текущему пользователю (без утечки существования чужой встречи), аналогично `GET /meetings/:id`.
- Хранилище метаданных записей встречи должно быть отделено от бинарного хранения самого файла, аналогично тому, как `MeetingsRepository` уже отделяет доступ к данным встречи.
- Статус «В обработке»/«Готово»/«Ошибка» выставляется внешним процессом обработки — эта фича лишь читает и отображает текущее значение статуса, не управляя переходами обработки.

## Критерии готовности

- [ ] На странице `/meetings/[id]` есть блок загрузки файла записи и список записей встречи.
- [ ] Пользователь может загрузить аудио/видеофайл в пределах допустимого формата и размера, и он появляется в списке со статусом «Загружено».
- [ ] Пользователь может загрузить несколько файлов записи к одной встрече, и все они отображаются в списке.
- [ ] Загрузка файла неподдерживаемого формата отклоняется с понятным сообщением об ошибке, файл не сохраняется.
- [ ] Загрузка файла, превышающего максимальный размер, отклоняется с понятным сообщением об ошибке, файл не сохраняется.
- [ ] Список записей отображает актуальный статус каждой записи: «Загружено», «В обработке», «Готово» или «Ошибка».
- [ ] Пользователь не может увидеть или загрузить записи для встречи, владельцем которой не является (проверено запросом от имени другого пользователя).
- [ ] Загруженный файл ставится в очередь/передаётся во внешний пайплайн обработки (факт постановки проверяем, без проверки результата самой обработки).
